CÁPSULA DO TEMPO — TERCEIRÃO 2026

COMO PERSONALIZAR
1. Nomes do grupo:
   Abra script.js e altere CONFIG.members.

2. Respostas reais dos alunos:
   No mesmo arquivo, altere CONFIG.capsules.
   Você pode adicionar ou remover mensagens dentro de cada categoria.

3. Vídeo da turma:
   Coloque o vídeo em:
   assets/memorias.mp4
   Recomendado: MP4 (H.264), até 4 minutos.

4. Capa do vídeo (opcional):
   Coloque uma imagem em:
   assets/video-poster.jpg

5. Música ambiente (opcional):
   Coloque a música em:
   assets/ambient.mp3
   O som só começa quando o visitante aperta o botão, respeitando as regras dos navegadores.

COMO ABRIR
- Para testar rapidamente, abra index.html no navegador.
- Para publicar, a pasta inteira pode ser enviada para Netlify, Vercel ou GitHub Pages.

CONCEITO
O site não substitui o slide nem o vídeo: ele funciona como a terceira linguagem do trabalho — a experiência interativa.
